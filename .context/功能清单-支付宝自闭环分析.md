> **整理日期**：2026-06-29

---

## 自闭环分级说明

| 标签 | 含义 | 判定标准 |
|------|------|---------|
| ✅ **支付宝自闭环** | 支付宝/百宝箱独立完成，不依赖任何 SKP 接口 | 静态知识库、LLM 推理、前端交互、百宝箱自有数据 |
| 🔵 **需SKP提供API** | 前端流程已通，但数据是假的/写死的，SKP 给 API 即可上线 | 静态数据 → 需替换为实时 API |
| 🟡 **需支付宝出能力** | 前端流程已通，但动作是假的，支付宝补上能力即可闭环 | 券只展示了但没真发、消息没真推 |
| ❌ **需双方共建** | 支付宝和 SKP 都要出能力，缺一不可 | 既有 SKP 数据依赖，又有支付宝能力依赖 |
